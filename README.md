## 📚 Conteúdo do Bootcamp

### 1. Fundamentos e Java Básico
* **Introdução ao Ambiente:** Instalação do JDK 24, configuração do IntelliJ IDEA e sintaxe básica.
* **Estruturas de Controle:** Domínio de condicionais (`if/else`, `switch case` com `yield`) e estruturas de repetição (`for`, `while`).
* **Tratamento de Exceções:** Debugging avançado e uso de `try/catch` para aplicações resilientes.

### 2. Programação Orientada a Objetos (POO)
* **A Arte da Abstração:** Criação de classes, atributos e encapsulamento de dados.
* **Reutilização de Código:** Implementação de Herança e Polimorfismo.
* **Interfaces e Funcionalidades:** Dominando Interfaces e Expressões Lambda.
* **Collections:** Manipulação de dados com Listas, Sets e Maps de forma eficiente.

### 3. Ecossistema de Desenvolvimento
* **Gestão de Dependências:** Uso prático de **Maven** e **Gradle** para automação de builds.
* **Versionamento:** Fluxo completo de Git (commits, push, merge e resolução de conflitos de histórico).

### 4. APIs REST com Spring Boot
* **Spring Framework:** Criação de aplicações escaláveis com Spring Boot.
* **Documentação:** Implementação de **Swagger** para APIs documentadas.
* **Segurança:** Proteção de endpoints utilizando **Spring Security**.
* **Design Patterns:** Aplicação de padrões de projeto clássicos (GoF) integrados ao Spring.

### 5. Docker & Preparação para Nuvem
* **Containerização:** Criação de `Dockerfiles` e orquestração com `Docker Compose`.
* **Persistência em Containers:** Gerenciamento de volumes, redes e logs em ambientes Docker.

### 6. Cloud Services (AWS)
* **Infraestrutura Global:** Conceitos de regiões e zonas de disponibilidade.
* **Serviços AWS:** Experiência prática com computação, redes, armazenamento e bancos de dados na nuvem Amazon.
* **Otimização:** Foco em redução de custos e alta disponibilidade.
